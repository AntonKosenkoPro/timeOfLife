| Index | Requirement                                                                                                                | Comment                                                                                           |
| ----- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| F1    | A user can create, edit, and delete saved **activities** (name + color + SF Symbol icon + notes)                          | Replaces the MVP's throwaway free-text names. An activity can be tagged with zero or more categories. |
| F2    | A user can create, edit, and delete **categories** (name + color) and tag activities with them                             | Multiple category tags per activity (many-to-many).                                               |
| F3    | Typing a new name on the timer and starting auto-creates a saved activity                                                  | Case-insensitive: if the name matches an existing activity, it is reused instead of duplicated.   |
| F4    | The timer screen suggests the user's most recently used activities (top 3–5)                                               | One tap prefills the name and links the activity to the entry.                                     |
| F5    | A default, localized (EN + RU) set of activities/categories is seeded on first run after sign-in                           | Editable and deletable by the user.                                                                |
| F6    | Deleting an activity that has past entries asks the user for the scope: delete the entire activity, or delete only the current entry | "Unlink from activity" is a separate per-entry action, not part of delete. Deletions are undoable for 30 s in-app plus shake-to-undo until the next undoable action or app relaunch. |
