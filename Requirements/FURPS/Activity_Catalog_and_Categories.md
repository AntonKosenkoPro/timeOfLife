# Activity Catalog & Categories — FURPS

Requirements for **Epic 1: Activity Catalog & Categories** (`Epics.md`). This epic turns the MVP's free-text timer into a structured, reusable catalog of activities and category tags, and surfaces recency-based suggestions on the timer screen.

App-wide requirements (minimalism, dark/light, offline, EN+RU localization, HIG, secure storage, linters, tests, CI, OpenAPI, `AGENTS.md`) live in [`Common.md`](./Common.md) and are not repeated here; only feature-specific rows are listed.

| F1    | Create, edit, and delete **activities**. An activity has a name, optional notes, and zero or more category ids.                                                        | Replaces the MVP's throwaway free-text `activityName`; category-derived representation is resolved from the synced catalog.                                                                                            |

| F4    | Starting a timer by typing a name that matches no existing activity **auto-creates** a new activity and links the entry to it.                                          | Name matching is case-insensitive and trims surrounding whitespace; a matching existing activity is **reused** (no duplicates). The auto-created activity has no categories; categories can be assigned later.         |
| F5    | The timer screen shows **suggestions**: the user's 3–5 most recently used activities, computed **on-device** from the local catalog.                                  | No server endpoint: the client ranks its synced activities by `last_used_at` and takes the top 5 (works fully offline). [^1]: The auto-created activity is a first-class record: it appears in suggestions next time and can be edited to add categories. The user is never forced to open the catalog to start a timer — typing a name and starting still works in one step (F4).

## Resolved decisions

- **Sync conflict policy** (R2): last-write-wins on `updated_at`; no field-level merge at MVP.
- **Seed set** (F6): 7 categories — Work, Hobby, Sport, Education, Relax, Sleep, Entertainment (EN/RU). No starter activities.
- **Limits**: no count caps enforced at MVP; name ≤ 60 chars, notes ≤ 280 chars.
- **Manage Activities ordering** (F8): no manual reorder at MVP; list is recency-ordered (most-recently-used first).
